# dedi-crawler test fixtures — domains.txt
#
# These are NOT real hostnames. Each entry is a GitHub Pages path acting as
# a stand-in "domain": https://<entry>/.well-known/dedi.index.json is where
# the crawler will look for each manifest. Because these entries carry a
# path (not a bare hostname), crawling this list requires the crawler's
# discovery.allow_non_standard_domains: true (and verify's matching
# AllowNonStandardDomains option), per dedi-crawler's config.go — never
# enable that flag against real, untrusted, internet-crawled content.
#
# The domain/publisher.domain/namespace values *inside* each manifest and
# DeDi file are separate, dummy-but-realistic-looking domains (e.g.
# beckn-mobility-network.example) — intentionally different from the paths
# below, since AllowNonStandardDomains also skips the domain-binding check
# that would otherwise require them to match.
